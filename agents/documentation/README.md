# Documentation Agents

This directory contains custom agents that help create, maintain, and improve documentation.

## Available Agents

### [api-doc-generator](./api-doc-generator/)
Generates comprehensive API documentation from code comments and structure.

**Use Cases**:
- OpenAPI/Swagger generation
- API reference documentation
- Documentation updates

**Version**: 1.0.0  
**Status**: ✅ Active
