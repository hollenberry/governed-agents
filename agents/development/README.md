# Development Agents

This directory contains custom agents focused on software development tasks.

## Available Agents

### [code-reviewer](./code-reviewer/)
Reviews code changes for style, bugs, best practices, and potential improvements.

**Use Cases**:
- Pull request reviews
- Pre-commit code quality checks
- Learning tool for best practices
