# Security Agents

This directory contains custom agents focused on security, compliance, and vulnerability detection.

## Available Agents

### [secrets-scanner](./secrets-scanner/)
Scans code for accidentally committed secrets, API keys, passwords, and sensitive data.

**Use Cases**:
- Pre-commit secret detection
- Pull request security checks
- Security audits

**Version**: 1.0.0  
**Status**: ✅ Active
